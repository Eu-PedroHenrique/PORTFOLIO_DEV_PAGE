# Portfólio Dev

Projeto desenvolvido durante os estudos na **Rocketseat**, com o objetivo de praticar a construção de uma página de portfólio para desenvolvedor a partir de um layout proposto.

O foco do projeto está na implementação da interface e na aplicação prática dos fundamentos de HTML e CSS.

> **Observação:** os dados, nome, serviços e informações profissionais exibidos na página fazem parte do conteúdo demonstrativo do layout e não representam minhas informações ou competências profissionais.

## 🎯 Objetivo

Praticar a transformação de uma referência visual em uma interface web, trabalhando a estruturação da página, organização dos estilos e construção de diferentes componentes visuais.

## 🛠️ Tecnologias

- HTML5
- CSS3

## 📚 Conceitos praticados

Durante o desenvolvimento foram trabalhados conceitos como:

- HTML semântico
- CSS Grid
- Organização modular de CSS
- Variáveis CSS
- Tipografia e hierarquia visual
- Espaçamentos e composição de layout
- Estados de interação com `:hover`
- Organização de assets e ícones

## 🧩 Estrutura da página

A interface é composta por diferentes seções:

- Apresentação
- Projetos
- Serviços
- Contato

Os estilos foram separados em diferentes arquivos CSS de acordo com as áreas da página, facilitando a organização e manutenção do código.

## 📖 Contexto

Este projeto faz parte da minha trajetória de estudos em desenvolvimento web e foi utilizado para colocar em prática conceitos apresentados durante a formação da Rocketseat.

O objetivo do repositório é registrar minha evolução e experiência prática com a construção de interfaces utilizando HTML e CSS.
